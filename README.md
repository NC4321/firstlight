# firstlight

> In astronomy, *first light* is the moment a new telescope captures its first image.
> This tool is that moment for your code.

`firstlight` scaffolds a new project — folder structure, README, license, `.gitignore`,
CI workflow, git init, even the GitHub repo — in one command, for Python, Node/TypeScript,
or Go.

**Status: under construction.** Full README (install, usage, demo) lands with v0.1.0.

## Development

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e .[dev]
pytest
```
